# Student Management System

A simple single-page application for managing student enrollments. Built with **FastAPI** (backend) and **React** (frontend).

## Features

- Add new students to the system
- Assign each student to a specific course instantly upon creation

## How It Works

This is a minimal student management system where users can register a student and simultaneously enroll them in a chosen course—all from a single, streamlined page.

## Tech Stack

- **Backend:** FastAPI
- **Frontend:** React (SPA)

## Quick Start

1. Clone the repo
2. Run the FastAPI backend
3. Serve the React frontend
4. Open the single-page interface and start managing students

---

> *Note: This is a lightweight implementation focused on core functionality—add a student and assign a course in one go.*
